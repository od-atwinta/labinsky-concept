# Концепт главной страницы — АО «ППЗ «Лабинский»

Демонстрационный концепт главной страницы сайта племенного птицеводческого завода
«Лабинский» (Краснодарский край), подготовленный ООО «Атвинта».

Что показано: шапка с меню и поиском, слайдер первого экрана, краткий блок
о предприятии, продукция (пищевые яйца и племенная продукция), качество,
преимущества, новости и закупки, форма обращения, подвал. Отдельно — мобильная
версия первого экрана.

Цветные прямоугольники — места под фотографии, подписи внутри говорят, что
на них должно быть. Слоганы взяты из технического задания заказчика.

ООО «Атвинта», сентябрь 2026.
